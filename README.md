# Bane video-edit skills

Pet projektnih skillova za Baneove vertikalne video formate. Svaki skill ima svoj `SKILL.md`; povezane reference i primeri nalaze se u istom folderu. Korisnikove instrukcije za konkretan video uvek imaju prednost.

| Skill | Format |
| --- | --- |
| [bane-2-nivoa](skills/bane-2-nivoa/SKILL.md) | Dve uporedne opcije sa labelama, logotipima i karticom teme |
| [bane-3-nivoa-edit](skills/bane-3-nivoa-edit/SKILL.md) | Tri ocene: LOŠE, DOBRO, SUPER |
| [bane-ss-edit](skills/bane-ss-edit/SKILL.md) | Talking head sa punim kadrom, split screen demonstracijama i titlovima |
| [kodovi-edit](skills/kodovi-edit/SKILL.md) | Numerisane AI komande, demonstracije unosa i rezultata, titlovi i završni profil |
| [ne-gpt-za-sve](skills/ne-gpt-za-sve/SKILL.md) | Talking head sa kategorijama i karticama za ikone alata |

Folder `skills/` je spreman za instalaciju kao kolekcija Codex/Claude skillova. Skillovi opisuju postupak i izgled; izvorni snimci, eksporti i privatni mediji nisu uključeni.

Ranije objavljeni `bane-ss-edit` ostaje i u korenu repozitorijuma radi postojećih linkova; zbirka u `skills/` sadrži njegovu kopiju zajedno sa ostala četiri stila.

`bane-ss-edit` sadrži primerne HyperFrames JSON šablone u `references/hyperframes-templates/`; njihova Apache 2.0 licenca je sačuvana u tom folderu.
